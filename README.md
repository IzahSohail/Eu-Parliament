# EU Parliament Voting Data Project

## Project Description
This Django project analyzes European Parliament voting data for the 10th parliamentary term (EP10).  
It includes information about Members of European Parliament (MEPs), political groups, vote results, and more.

---

## 📂 Project Setup Instructions

### 1. Clone or Download the Project
Make sure you have all the project files and folders on your local machine.

If you're receiving a zipped folder, extract it first.

---

### 2. Install Required Tools

- **Python 3.9+** (recommended)
- **PostgreSQL 14+** (database)
- **Virtualenv** (for Python environment management)
